- Communicate in Chinese; keep H3 prompt fields and prompt text in English where required by the model format.

- Preserve the official MiniMax H3 section names and ordering. Link to the official source instead of copying its skill text.
- Before publishing case studies, remove local paths and check that product/customer information is appropriate for a public repository.
- Do not delete files in batches. Delete only one explicit file at a time.
