## Scope

This repository shares prompt structures and practical observations. It does not include source images, videos, private asset paths, or model guarantees. A prompt marked verified was confirmed for its stated references and settings; results can still vary with model versions, inputs, and generation parameters. Each prompt states its validation status; pending prompts are not presented as successful results.
